# راهنمای نگارش فارسی (FA style guide)

هدف: متنی روان مثل یک بلاگ فنی خوب فارسی — نه ترجمه‌ی واژه‌به‌واژه.

## اصول

1. جملات کوتاه و طبیعی بنویسید.
2. اصطلاحات Kubernetes/CNCF را دقیقاً به انگلیسی نگه دارید: Pod, Node, Deployment, Service, Namespace, kubelet, API server, etcd, Helm chart, CRD, sidecar, container, image.
3. نام محصول‌ها انگلیسی بمانند: Kubernetes (نه کوبرنتیز). نام اپ: «اطلس Cloud Native».
4. اولین بار که اصطلاح می‌آید، توضیح کوتاه فارسی بدهید: «Pod (کوچک‌ترین واحد اجرا در Kubernetes)».
5. هر دنباله‌ی لاتین را در `<bdi>` یا اسپن Term/Code بپیچید تا bidi خراب نشود.
6. جمله را با واژه‌ی لاتین شروع نکنید؛ جمله‌بندی را عوض کنید: «ابزار kubectl، Deployment را به API server می‌فرستد.»
7. نیم‌فاصله (ZWNJ) درست: می‌شود، نمی‌کند، دیاگرام‌ها، زیرخط‌دار، داده‌ی.
8. نشانه‌گذاری فارسی: ، ؛ ؟ و گیومه « ».
9. ارقام در نثر فارسی، در کد/دستور/پورت لاتین.
10. فقط ی و ک فارسی؛ از حروف عربی هم‌ظاهر پرهیز کنید.

## ممنوع

- پاد / نود / سرویس به‌جای Pod / Node / Service
- شکستن واژه‌ی لاتین وسط کلمه در دیاگرام
- گیومه‌ی ASCII `"` داخل رشته‌های fa
